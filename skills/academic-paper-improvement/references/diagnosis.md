# 体检手册：六类检查的判据与失败模式

按顺序执行，前一类不过不进入后一类。每类给出"通过判据"和"该类别里真正致命的失败"，避免无差别挑错。

本文件不含任何具体稿件的对象信息。文中示例一律用占位符号，执行时替换为本次稿件的实际内容。

---

## 0　禁令体检（排在定标之前）

六条禁令先扫，不看内容质量：

| 编号 | 扫描对象 | 命中处理 |
|---|---|---|
| 禁令 1 | 课程／课程论文／本课程／课件／讲义／课堂／教材／结课／学时／课后 | 逐句改写：来源改"文献""公开报道"或省去；不得为避词编出处 |
| 禁令 2 | 破折号「——」 | 逐句改：解释→冒号，补充→逗号，独立判断→句号 |
| 禁令 3 | 本次改动是否用了脚本批量替换 | 用了就撤回重做，逐句改 |
| 禁令 4 | 稿件中每个数值、曲线、案例的来源 | 只追到教学材料的，按 回溯 → 降级 → 删除 三步处理；不得改挂未核实文献、不得列入参考文献、不得改单位 |
| 禁令 5 | 提交方式与仓库内容 | `git status --short` 列出待提交清单；出现渲染件、`.bak_*`、教学材料即剔除；用 `git add <明确路径>` 重做；仓库缺 `.gitignore` / `pre-commit` 时先补机制 |
| 禁令 6 | 对偶否定句式（九种形态） | 逐句改：拆成两句、只留肯定、或换成程度表述；引述原文须加引号并标来源 |

**禁令 4 的底账怎么做**：把全稿数字抓成一张表，五列（数值 / 位置 / 来源类别 / 公开出处 / 证据等级），来源类别只填四种：公开文献、现行标准、教学材料、无来源，后两种数量必须为 0，否则不能进入下一步。证据等级按铁律 5 填 E1–E4，同时记下正文现写法，用于判断有无虚报（E2 写了区间端点、E4 写了具体数值）。做不出这张表，说明还没核对过，不能声称"数据均有出处"。

**为什么排第一**：这几类问题不伤论证，但每次交付都要被逐字核对，且改稿过程中最容易被自己重新引入（补一句来源说明就写进禁词，加一处解释就打出"——"，赶字数就把教学材料里的数字搬进来）。基线先归零，交付前再扫，两次都为 0 才继续。

命中数必须报出：`禁词 0 处、破折号 0 处、教学材料来源 0 处`。不许写"已检查"了事。

## 1　定标（先确认，不改稿）

必须得到四项确认，否则不动笔：

1. **字数口径**：汉字数 / Word 字数 / 字符数（三者差可达 30%）。
2. **字数上下限**：只有下限还是有上限。上限的来历要问清楚，别自行假定。
3. **格式依据**：任务方标准原文、机构格式文件、期刊模板，三者要求不同。
4. **本次改动的边界**：可否增删章节、可否改数据、可否换文献。

产出：一句话的"验收标准"，附口径与依据。字数与文献下限由任务方给定，脚本以参数接收，不照抄默认值。

## 2　结构（S）

**通过判据**

- 题名、作者信息、中英文摘要、关键词、正文、参考文献齐全（A5）。
- 摘要含目的、方法、结果、结论；中英文等值（英文与中文等值，不作删节版）。
- 章节编号连续、不跳级（B 层章节编号规范）。
- 引言提出的问题，结论逐一回答。
- 全文主体对象唯一（A2）。

**致命失败**

- 摘要宣告的创新点，正文无对应段落 → 独立见解（A8）不成立，这是最高优先级缺陷，先于一切措辞问题。
- 引言提三问，结论只答两问 → 论证链断裂。
- 中英摘要不等值（中文有限定语，英文没有）。
- 标题聚焦一个对象，正文并行讨论多类对象。

---

## 3　论证（L）

**通过判据**

- 每个论断可回答"凭什么"：文献、数据、公式、或明确的推理链。
- 反例与代价被写出（工程类论文尤其需要：某方案为什么不能随便用）。
- 比较有共同基准（同一测试条件、同一口径）。
- 结论强度与证据强度匹配。

**致命失败**

- 只给结论不给机理（说某步骤重要，却不说为什么）。
- 同一性质在不同章节评价相反（一处优点、一处缺陷，互不承认）。
- 用平衡态公式解释速率；用理想模型解释非理想体系而不加边界。
- 判据只有数字没有物理含义，读者无法迁移。

---

## 4　证据与引用（E）

**通过判据**

- 每个外部数据点有引注；引注对象与本句一致（无引证错配）。
- 顺序编码制：编号按正文首次出现递增，文后同序，编号连续无缺号。
- 参考文献条数达到下限（A12），且每条真实可查。
- 图表有编号、标题、来源；转载注明出处。
- **每个数值标注了证据等级（E1–E4），且正文措辞不超出该等级**（铁律 5）。
- **摘要与结论中同一论断的措辞，不高于正文最弱的那条证据**。

**致命失败**

- 数据无引注，或用"已有研究表明""据工业实践"充当出处。
- 文献元数据编造（页码、卷期、DOI 与原文不符）。
- 正文引用了文后没有的编号；某条文献从未被正文引用。
- 标准引的是已废止版本，或把修订草案写成现行限值，或漏注修改单。
- **虚报等级**：只见综述量级却写精确区间（E2 撑 E1）；公式算出的值写成"实测"或挂引注（E3 冒 E1）；正文已降为机理推断，摘要仍写"实测""经验规律"（E4 撑 E1）。
- **降级不回扫**：正文删了数据，摘要、引言、结论三处对应提法原样留着。

**等级怎么判**（避免自欺）：问一句"我现在能不能指出页码、表号或条款号"。能，E1；只能指出文献但指不出页，E2；只能给算式，E3；什么都指不出，E4。**答不上来就按低一级算**，宁可写"机理上应"也不要写"实测为"。

细节见 `anti-fabrication.md`。

## 5　表述（W）

**通过判据**

- 无教学口吻、无应试语、无口语（A6）。
- 术语一词一义，全文统一（A7）；缩写首次出现给全称。
- 句子主语明确，无悬空指代（"上述""这一判断""该方案"要能指回具体对象）。
- 不出现"我们""众所周知""显而易见""不难看出"。
- 不叙述写作安排：不出现"值得展开""留待某节讨论""下面将""本节先""本文要做的是"。要写的是研究内容，作者接下来打算写什么不属于其中。
- 不宣告写作决策："本文认为""本文选择"改为直接给出结论与其理由；作者的态度不构成论据。

**致命失败**

- 批量替换留下的痕迹：指代落空（"上述看似分散的规律"但上文没有列举）、伪归属（"已有研究指出"而该段无引注）、单位口径不一致。
- 同一量在全文有三个名字（例如"倍率""比率""比值"混用指同一对象）。
- 绝对化表述无支撑："完全""必然""公认"。
- 以"值得展开""留待讨论"替代实际论证：读者读到的是写作计划而非研究内容，论文体退化为提纲。此条最易漏，因为句子本身通顺、不含任何禁用词。

---

## 6　格式（F）

**通过判据**

- 数值范围用浪纹线"～"，不用"~""-""—"（B 层数字用法）。
- 数值与单位符号间留空隙；单位符号正体、量符号斜体（B 层量和单位）。
- 编号类引用照抄原文格式，连接号与年份写法不得自行改动；章节编号用阿拉伯数字分级（B 层编号规范）。
- 标点：中文语境用中文标点；连接号按用途选型（B 层标点规范）。
- 参考文献著录格式统一（B 层著录规则）；关键词 3~8 个。
- 表格三线、表题在上、表注在下、不跨页；图为黑白可辨。

**致命失败**

- 参考文献条目格式在同一篇内混用两种体例。
- 表格跨页断行导致数据错位。
- 上下标丢失或渲染为纯文本（化学式、幂次）。

---

## 检查顺序的理由

结构不过，改措辞是白费；论证不过，改格式是粉饰；证据不过，一切结论无效。所以顺序固定为 禁令体检 → 定标 → 结构 → 论证 → 证据 → 表述 → 格式 → 机械核验。

**每类只报该类的致命项与可执行项**，不做无差别罗列。用户明确反对"广撒网"。
