# 反编造规程

改进论文时，最常发生的是三类"看起来没问题"的编造：编一条文献、编一个数字的出处、编一条规范要求；语句错误反而容易察觉。本文件规定核验动作，**未完成核验的内容不得写入稿件**。

本文件不含任何具体文献、规范编号、行业数据与年份。示例用占位符号表示，执行时替换为本次稿件的实际对象。

---

## 一、文献：元数据必须逐条落地

### 必查字段

作者（全部或前三位 + et al.）、题名、刊名、年、卷、期、起止页码或文章号、DOI。

### 核验方式

1. 首选 Crossref：`https://api.crossref.org/works?query.bibliographic=<题名>&rows=5`，比对返回的 `title / container-title / volume / issue / page / published`。
2. 无 DOI 或检索不到，改用期刊官网、PubMed、Web of Science 记录；仍无，**不得引用**。
3. 中文文献查 CNKI / 万方 / 维普的题录页，核对卷期页。
4. 规范类文献查发布机构的官方平台，核对编号、名称、**状态（现行/废止/被代替）**、发布与实施日期。

### 三条硬禁令

- **不得凭印象补页码、补卷期、补 DOI**。缺字段就先空着，标注"待核"。
- **不得因"看起来像"而推断文献内容**。只写文献实际讨论的对象；把 A 主题的文献用于支撑 B 论断，属引证错配，等同编造。
- **不得把 DOI 尾号当作文章号**。部分期刊的 DOI 内部号与文章号不同，著录以文章号为准。

### 引证错配的识别

对每条引注问一句"这篇文献是否真的研究了这个对象"。典型错配有：用甲体系的文献支撑乙体系的结论；用工艺类文献支撑环境或归趋类判断；用某性能的文献支撑另一性能的级配结论。

---

## 二、数据：每个数字都要能指认来源

| 数字类型 | 要求 |
|---|---|
| 实测/文献值 | 必须有引注，且引注中的对象、条件与本句一致（浓度、温度、测试标准） |
| 计算/推导值 | 必须写出算式或指向本文公式编号，可复算 |
| 标准限值 | 必须给标准号 + 年份 + 具体指标，且为现行版本 |
| 综述性区间 | 必须给"据文献报道"的引注范围，不得给单一来源撑全区间 |
| 产业数据（产量、产能、市场份额） | 必须有可查来源；查不到就删，不得估 |

**禁止**：为凑论证强度把"可能""推测"改成断言；把单一体系的数据说成"普遍规律"；把模拟结果写成实验结论。

### 2.1　教学材料只作传递环节（禁令 4）

课件、讲义、课堂板书、教学视频、校内习题与答案，属于**传递环节**，够不上**原始出处**。它们给出的数值往往来自某本专著或某篇论文，但经过简化、改写与四舍五入，单位口径也常被改动。因此：

| 情形 | 处理 |
|---|---|
| 数字能在公开文献中找到，且版本一致 | 引公开文献，不引教学材料 |
| 只能追到教学材料，回溯不到公开文献 | **降级**：删去具体数值，改为定性表述；或**删除**整句 |
| 该论断的唯一支撑就是这个数字 | 整句删除，并检查摘要、引言、结论中是否还有对应提法 |
| 教学材料与公开文献数值不一致 | 以公开文献为准；差异明显时不得"折中"，须说明取哪一个及理由 |

**三种伪补救，与编造同罪**：

1. **改挂**：把数字挂到一篇没核实过的文献上（"看起来这篇应该讲过"）。
2. **入表**：把教学材料写进参考文献表，凑条数或充来源。
3. **改口径**：改动数值或单位，使其"像文献值"。典型做法是把教学材料里以质量计的用量改写成以分数计的百分比，既换了来源，又编了基准，数字还失去原意。

教学材料唯一正当的用途：理解概念、发现选题、判断哪些方向值得查文献。它不进稿件，也不进文献表。核验脚本的 `R7` 会对文献表中的教学材料类条目报 FAIL。

### 2.2　有出处，还要问撑不撑得住

查到了引注不等于这个数字能在正文里那样写。"看到了原文"与"只看到综述里说大约某个量级"是两种证据，能支持的写法差别很大。

| 等级 | 判定问句 | 可以写 | 不可以写 |
|---|---|---|---|
| **E1 逐字** | 我能指出页码、表号或条款号吗 | 精确值、区间端点、小数、"测定为""标准规定为" | — |
| **E2 量级** | 我能指出文献，但指不出页吗 | "约""量级""数个数量级" | 精确区间端点、"实测为" |
| **E3 可复算** | 这个数是我按公式算出来的吗 | "按式（n）估算"，附算式 | 挂引注（公式不是文献）、"实测" |
| **E4 定性** | 我什么都指不出，只有机理推理吗 | "机理上应""通常""可以预期" | 任何具体数值 |

**两种最常发生的虚报**：

1. **综述区间当实测**：文献综述给的是量级，正文写成了精确区间。端点是从别处推的，一旦被问"哪篇文献的第几页写了这个端点"，就答不上。要么取到原始文献升 E1，要么保留量级表述。
2. **删了数据，结论没跟着降**：正文里唯一支撑某个规律的实测序列被删（因来源不合规），该规律只剩机理推断，成了 E4，而摘要、引言、结论仍写"实测表明""经验规律"。**这是最隐蔽的一类**，因为三处都不在改动范围里，改完正文就以为完事了。

**降级后必须回扫三处**：摘要、引言、结论。逐处问"这里对这个规律的措辞，比正文现在能撑住的强吗"。强了就改，没有对应提法就记"无"。摘要与结论取全文最弱的那条证据。

**E 级是本规则集的工作定义**，学界并无此通用术语，不得在论文里当作方法论主张写出，也不得对外称"按 E1 标准核验"。

## 三、规范与法规：只引编号与要点，不造条文

- 引用规范只写"编号 + 名称 + 要点"，需要逐字引用时须查到原文。
- **不得编造条款号**，除非确实看到原文。
- 引用限值、检验方法、分类时，先确认该版本是否现行；机构名称按发布时点写，机构改革前后发布单位可能不同。
- 规范的"修订计划"不等于"已实施的新限值"。修订计划编号、草案内容只能表述为"修订计划中的拟调整项"，不得写成现行要求。

### 3.1　规范状态四分（漏一档就会误导读者）

| 状态 | 写法 | 怎么确认 |
|---|---|---|
| 现行 | 编号 + 发布年 + 名称，三者齐 | 发布机构官方平台的状态栏为"现行" |
| 现行含修改单 | 主编号之后另注"含某年第 N 号修改单" | 查该编号下有无修改单文件；**修改单会改指标，只写主编号会让人按原版理解** |
| 被代替 | 主编号 + "已被某编号代替" | 状态栏"被代替"并给出代替者 |
| 征求意见稿／修订计划 | 只能写"修订计划拟将某项调整为……" | 发布机构平台的"计划"栏目；**不得与现势词同句**（"现行""规定为""限值为"） |

本文件不记录任何编号本身。编号与年份一律向发布机构的原文核对，不得沿用二手转述，也不得凭记忆补全。

修改单这一档最容易漏，因为它不改主编号，检索时看不出异常。凡是正文写"现行规范"的，都要多查一次有没有修改单。

本文件对编号一律用占位形式，实际编号与年份向原文核对，不得沿用任何二手转述。

## 四、推断与结论的边界

- 本文未做的实验、未测的参数、未验证的工艺，**只能写为推断或待验证命题**，并给出验证路径（测什么、怎么测、判据是什么）。
- 摘要中出现的"本文提出"，正文必须有对应论证段落；否则删去"提出"，改为"设想"或补论证。
- 局限性陈述必须与正文一致：正文说"已给出工艺路径"，局限段就不能说"仅停留在设想"。

---

## 五、核验失败时的处理

| 情形 | 处理 |
|---|---|
| 文献查不到 | 删除该引注，改写论断为不需引证的表述，或替换为已核实的文献 |
| 数据无来源 | 删除数字，改为定性表述；不得保留"约""左右"来掩盖无出处 |
| 规范已废止 | 换为现行版本；若必须引旧版本，注明"已被某版本代替" |
| 论断强于证据 | 降级表述（"表明"→"提示"，"证明"→"与…一致"），或补证据 |

**任何情况下，宁可删掉一句话，不可编一个出处。**
