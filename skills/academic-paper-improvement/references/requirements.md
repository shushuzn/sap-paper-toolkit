# 论文改进要求：来源与条文

本文件是本 skill 的唯一要求依据。**任何改进意见必须能追到 A、B、C 三层之一并注明层级**；追不到的，只能记为"建议（非要求）"并说明理由。

本文件不记录任何具体任务的对象信息。层内的数值是通用量级，实际执行须以任务方提供的原件为准；原件与本文件冲突时，以原件为准并在交付记录里写明差异。

---

## A 层　任务方评分标准

**来源**：任务方书面给出的评分标准或验收口径，须取到原文。
**纪律**：A 层条文不得转述为"一般要求"。原文没写的项，不构成判罚依据。

### A 层拆成可判定项

| 编号 | 要求 | 判定方式 | 常见失败 |
|---|---|---|---|
| A1 | 选题落在任务方给定范围内 | 能指认与给定范围的对应关系；无关联段落即判失败 | 写成通用综述，给定范围只在引言出现一次 |
| A2 | 聚焦一种 / 一个系列对象 | 全文主体对象唯一；出现第二个平行主体即失败 | 标题聚焦一个对象，正文发散成多类对比 |
| A3 | 无抄袭剽窃、查重合格 | 引文有出处；长段复述他人观点须标注 | 大段改写他人综述而不标注 |
| A4 | 引用他人观点、数据、图表规范标注 | 每个外部数据点有引注；图表转载注明来源；**引注须为公开可核验来源，教学材料不在此列** | 数据无引注、"已有研究"无文献、把教学材料里的数值当文献值 |
| A5 | 符合学术论文格式 | 见 S 层；另需题名、作者信息、中英文摘要、关键词 | 缺英文摘要、缺关键词、无作者信息 |
| A6 | 语言简洁专业，无口语化、错别字、语法错误 | 通读；机械扫描风险词表 | 教学口吻词、第一人称、"众所周知""需要记住" |
| A7 | 术语准确、无歧义 | 术语全文统一；一词一义 | 同一量在全文有三个名字 |
| A8 | 有独立思考与创新视角 | 摘要宣告的创新点，正文有对应论证段落，结论有收口 | 只在摘要宣布，正文无论证 |
| A9 | 对工艺或方法提出改进思路、对领域问题提出差异化对策 | 有具体工序、参数窗口、判据，不落口号 | "应加强研发""提高性能" |
| A10 | 不照搬文献 | 有本文自己的判断、比较、取舍 | 章节顺序与某篇综述一致，段落为其改写 |
| A11 | 正文达到字数下限 | 先确认字数口径再统计（见下） | 口径不清导致自证不成立 |
| A12 | 参考文献达到条数下限 | 计数真实文献条目，不含重复 | 凑数、同一文献拆条 |

**字数口径必须先与任务方确认，不得默认**：汉字数（仅 `[\u4e00-\u9fa5]`）、Word"字数"（含英文词与数字串）、Word"字符数"三者差异可达 30% 以上。报数时必须写明是哪一个。A11、A12 的下限由任务方给定，脚本以 `--min-chars`、`--min-refs` 接收，不写死在规则里。

## S 层　机构格式文件（排版与结构的强制来源）

**来源**：任务方或所在机构发布的格式文件原件，须取到文件本身。
**纪律**：本层数值必须来自文件原文。**不得用"一般机构都这样"替代文件**；文件没写的项（如行距取整、表内字号、页数）不得作为不符要求判罚。

### 本层最重要的区分：格式参照 ≠ 身份照搬

格式文件常被要求"参照"使用。参照的是**排版参数**，与这篇稿件的**类型身份**无关。同为一份文件里的条款，可分三类，处理方式完全不同：

| 类别 | 内容 | 处理 |
|---|---|---|
| **可直接参照**（纯排版参数） | 纸张、页边距、页眉页脚距离、行距、段前后、各级字号与字体、对齐、标题编号层级、三线表线型、表题位置、公式编号、页码 | 照数值执行 |
| **需换算**（文件给的是另一种文体尺度） | 摘要字数、题名长度、正文字数、文献数量与年限 | 只作参考量级；正文按 A 层与任务方要求，冲突时以 A 层为准 |
| **不得照搬**（另一种文体的身份要件） | 页眉中的机构名与论文类型字样、封面、诚信声明、目录、致谢、附录、指导教师与答辩信息 | **一律不写入本文** |

第三类的危害在于**让读者误认本文的类型**，属冒用文体，比任何排版偏差都严重。正确做法是页眉留空，只保留页眉距与页码。

| 编号 | 项目 | 文件规定（通用量级，以原件为准） |
|---|---|---|
| S1 | 纸张与页面 | A4；页边距上 2.7、下 2.7、左 2.7、右 2.7；页眉 1.8；页脚 1.85（单位 cm） |
| S2 | 段落 | 行距**固定值 20 磅**，段前、段后均为 0 磅（标题另行规定） |
| S3 | 页眉页脚 | 页脚插入页码、居中，页码距边界 1.85 cm → **可参照**。页眉距 1.8 cm 可参照；页眉文字若为机构名加论文类型，属**身份标识，本文不得使用**，应留空（见上表第三类） |
| S4 | 题名 | 黑体三号居中，长度上限见文件 |
| S5 | 中文摘要 | 标签"摘要"黑体加粗五号、段前空两个汉字字符；内容楷体五号；字数上限见文件 |
| S6 | 关键词 | 标签黑体加粗五号、段前空两字；内容楷体五号；术语用分号隔开；数量一般 3~6 个 |
| S7 | 英文摘要 | Abstract / Key Words 标签 Times New Roman 加粗五号、段前空两字；内容 Times New Roman 五号；关键词用逗号隔开 |
| S8 | 正文 | 宋体五号；数字、字母用 Times New Roman 五号 |
| S9 | 一级标题 | 楷体加粗四号居中；序号与文字间空 1 个汉字字符；段前、段后 6 磅（或 1 行）；编号 1、2…（理工科） |
| S10 | 二级标题 | 黑体加粗小四；段前空两个汉字字符；序号与文字间空 1 字；段前后 3 磅；编号 1.1、1.2… |
| S11 | 三级标题 | 黑体五号；段前空两字；段前后 3 磅；编号 1.1.1… |
| S12 | 三级以下 | 宋体五号；段前空两字；编号 1.1.1.1… |
| S13 | 注释 | 页末注（脚注，注文放本页下端）或篇末注；序号用 ①②③ |
| S14 | 正文引用标注 | 序号法或人名法（作者，年份）——**由二级单位自行确定，须统一**。全文**唯一**由二级单位自定的格式项 |
| S15 | 标点 | 中文用全角标点，数字、字母、公式、参考文献表用半角；符号用法按现行公开规范执行 |
| S16 | 表格 | 三线表：顶线底线粗、栏目线细、不加竖线；表序表题在表**上方**，宋体小五居中，序号与题名空 1 字，题末不加标点；表注在表下；表序全文统一或逐章编，须连续；跨页接写重复表序并写"续表" |
| S17 | 插图 | 图序图名在图**下方**，宋体小五居中，序号与图名空 1 字，题末不加标点；图须自明、不与文字重复；照片建议 300 dpi 以上 |
| S18 | 公式 | 用 Word 公式编辑器；编号圆括号置于公式右侧行末，与公式间不加虚线；编号连续不重复不跳缺；引用写"由式（n）可见" |
| S19 | 量和单位 | 法定计量单位；单位名称全文一致，不并用全称与简称；数值后接单位符号 |
| S20 | 数字 | 测量统计数据一律阿拉伯数字；公历年月日用阿拉伯数字，农历用汉字；不大数目、约数可用汉字 |
| S21 | 参考文献 | 宋体五号；条数与外文占比、近五年占比见文件；按正文引用顺序编序；著录项目齐全、格式完全一致 |
| S22 | 结构顺序 | 文件给出的完整构成含封面、声明、目录、中英文摘要与关键词、正文、参考文献、致谢、附录。**其中封面、声明、目录、致谢、附录属该文体的构成要件，本文不适用**；本文可取的序列是"题名—中英文摘要与关键词—正文—参考文献" |
| S23 | 正文字数 | 文件按稿件类型分级要求；**该尺度属另一文体，本文按 A11 执行，不得混用** |

### S 层适用边界

1. 若任务方只要求"格式参照"某文件，则 S1–S21 作为格式依据，S22 的身份要件与 S23 的车数字数不适用。
2. S14 是唯一由二级单位自定项。不同版本写法可能不同，**稿件用一种写法不构成违规**，但须向任务方确认口径。
3. 文件未规定：表内字号、图表数量、页数、行距取整方式、是否双面打印。这些只能建议，不能判罚。
4. **S22 与 S3 的页眉文字不得套用**：凡封面、声明、目录、致谢、附录、答辩信息、机构页眉，一律不加。
5. 题名长度上限、摘要字数上限、文献近五年占比三项，若来自另一文体的质量标准，对本文属**参考量级**，不构成硬约束。是否执行取决于任务方是否另行说明，不得单方面判为"不合规"。

## B 层　公开规范（只写核验维度，不记录编号）

本层不记录任何规范编号、版本年份与发布机构。原因有两条：编号一旦写进规则文件，就等于把某一领域的依据固定下来，换成别的领域即失效；编号与年份会过期，写死反而误导。

**做法**：先确定本次稿件所属领域，再向该领域的公开规范体系取原文，按下列维度逐项核对。**不得虚构条款号**；引用具体条文前须看到原文。

| 核验维度 | 要点 | 怎么取到原文 |
|---|---|---|
| 参考文献著录 | 顺序编码制：按正文引用先后编号，序号加方括号，文后按序号排列；期刊析出文献的字段顺序为责任者、题名、文献类型标识、刊名、年、卷（期）、起止页 | 领域内通行的著录规则原文，或目标期刊的投稿指南 |
| 引文 | 引文须与所引语句相关、完整准确、有出处、与行文贯通 | 学术出版规范类文件 |
| 注释 | 注释的类型、体例与编排原则 | 同上 |
| 关键词 | 宜 3~8 个，置摘要之后，"关键词："引导，分号分隔 | 同上 |
| 表格 | 表格的构成、内容与编排要求；表题、表注、量与单位 | 同上 |
| 插图 | 插图的分类、构成与编排要求 | 同上 |
| 章节编号 | 用阿拉伯数字分级编号（1 / 1.1 / 1.1.1），层级不得跳级 | 科技文献编写类规范 |
| 标点 | 连接号分短横线、一字线、浪纹线，用法不同；书名号、引号的层级与套用 | 标点符号用法类规范 |
| 数字用法 | 数值范围用浪纹线"～"；年份写四位；计量数值用阿拉伯数字 | 出版物数字用法类规范 |
| 量和单位 | 量符号斜体、单位符号正体；数值与单位符号间留空隙（° ′ ″ 除外）；用法定单位 | 量和单位类规范 |
| 中文夹用英文 | 中文行文中英文词的空格、大小写、缩写首次出现给全称 | 中文出版物编排类规范 |
| 学术不端界定 | 剽窃、伪造、篡改等行为的界定；剽窃含观点、数据、图片等类型 | 学术出版规范类文件 |
| 学位论文编写 | 结构分前置、主体、结尾；摘要须含研究目的、方法、结果、结论 | 学位论文编写类规范（仅在本文属该文体时适用） |

**版本状态必须核验**：引用任何规范前确认其为现行版本，被代替的版本不得作为现行要求引用；修订计划中的拟调整项不得写成现行限值。核验途径是发布机构的官方平台，不是二手转述。

## C 层　学科惯例与通用规则（属惯例，须标明）

### C1　学科写作惯例（可辩论，但属通行做法）

- 结构遵循"引言—方法/机理—结果与讨论—结论"的论证顺序；引言须交代问题、现状缺口、本文任务。
- 摘要自足：不引文献、不出现图表编号、不含未定义缩写。
- 图表自明：脱离正文可读懂，有编号、标题、必要的量与单位。
- 结论回答引言提出的问题，不引入新论据。

### C2　已确认的通用写作规则（可复核，不绑定具体稿件）

| 编号 | 规则 | 依据 |
|---|---|---|
| C2-1 | 结论写成连贯论述，不写编号条目 | 论文的结论按连贯论述写，条目化会把论证降级为清单 |
| C2-2 | 机制解释、工艺比较同样不用"第一/第二/其一/其二"罗列 | 同上 |
| C2-3 | 正文、摘要、图表题注、注释**一律不得出现**下列词：课程、课程论文、本课程、课件、讲义、课堂、教材、结课、学时、课后。需指代材料来源时写"文献""公开报道"或省去；不得为避开禁词而编造出处。也不得用"需要记住""不难看出"等应试语 | A6；属最高优先级硬约束（SKILL.md 禁令 1） |
| C2-4 | 不得使用全局字符串替换处理语义性指称 | 批量替换"课程"这类词会导致指代落空、伪归属、单位口径不一致 |
| C2-5 | 摘要宣告的创新点，正文必须有论证段落，结论必须收口（三点闭合） | 创新点只在摘要与局限段出现、正文零论证，是常见缺陷 |
| C2-6 | 跨节回指必须与实际章节一致；同一性质在不同章节不得一处为优点、一处为缺陷 | 同一现象在两处的评价相反，逻辑即自相矛盾 |
| C2-7 | 数学判据须给可执行的取样范围；对数变换前检查定义域 | 要求"在 S=0 处取 lg S"这类做法，定义域不成立 |
| C2-8 | 平衡态公式不得用于解释速率；须写明公式适用边界 | 平衡态公式无时间项，撑不住速率判断 |
| C2-9 | 阈值判据须给物理含义，不能只给经验数字 | 只给数字的阈值，读者无法迁移到别的体系 |
| C2-10 | 单位口径必须带基准（质量分数写 %，不写无基准的质量值） | 同一段里质量值与百分比混写，读者无法判断基准 |
| C2-11 | 删改不得以减少说明性内容为代价换取字数达标 | 靠删说明压字数，等于用信息量换数字 |
| C2-12 | 每处改动给"原文—改文—依据"，逐处可核对；改前备份 | 逐字阅读后改，不接受批量替换 |
| C2-13 | **全文不得使用破折号「——」**。解释用冒号，并列或补充用逗号，独立判断另起一句。单字线「—」仅限连接号（如"结构—性能"），不在禁令内 | 破折号在中文科技写作中多被用作语气停顿，替代成本很低，禁用可读性不降 |
| C2-14 | **禁止以脚本批量替换改正文**（`str.replace` 全量替换、`sed -i`、`re.sub` 全局）。逐字读原句，一处一个改动，改后给「原文 → 改后」对照。构建脚本中的文献表、表体数据可按行处理，但须逐条断言定位 | 批量替换"课程"曾致指代落空、伪归属、单位口径不一致 |
| C2-15 | **教学材料不得作为数据来源或引用来源**。课件、讲义、课堂板书、教学视频、校内习题与答案，只能用于理解概念、发现选题；凡进入稿件的数值、曲线、案例、文献条目，必须能追到公开文献、现行标准或可核验的原始出处。追不到的按三步处理：回溯 → 降级为定性 → 删除。**禁止三种伪补救**：改挂未核实的文献、把教学材料列进参考文献表、改写数值或单位使其"像文献值" | 教学材料经过简化、改写与四舍五入，单位口径也常被改动，够不上原始出处 |
| C2-16 | **论断强度不得超过证据强度**。证据分四级：E1 逐字（看到原文，可指页码/表号/条款号）、E2 量级（只见摘要或综述量级，指不出页）、E3 可复算（由本文公式算出，须给算式）、E4 定性（仅机理推理，无数据）。匹配要求：E1 可写精确值与区间端点；**E2 不得写精确值与小数**，只能"约""量级"；E3 写"按式（n）估算"，不得挂引注、不得写"实测"；E4 不得出现任何具体数值。任何降级须**回扫摘要、引言、结论三处**，摘要与结论的措辞取全文最弱的那条证据。**E 级为本规则集的工作定义，非学界术语**，不得作为行业规范对外主张 | 实测序列删除后，规律只剩机理推断，而摘要与结论仍按实测措辞叙述，是反复出现的虚报 |
| C2-17 | **规范状态须四分标注**：现行；现行并含修改单；已被代替（注明代替者）；征求意见稿或修订计划（只能写"拟调整"，不得写成现行限值）。四种状态各用一句话说明，不合并。修改单无法机械识别，须人工查发布机构平台后补注 | 只写主编号会漏掉修改单；把修订计划的拟调整项与现行限值并列表述，会误导读者 |
| C2-18 | **提交不得用 `git add -A` / `git add .`**。先 `git status --short` 逐行确认，只 `git add <明确路径>`；交付目录中的目检渲染件、`*.bak_*` 草稿备份、被否的教学材料一律不入库。仓库须带 `.gitignore` 与 `pre-commit` 拦截 | 全量暂存会把渲染件、备份与教学材料一次带进库；只删文件不改机制必然复发 |
| C2-19 | **不得使用对偶否定句式**（不是 A 而是 B、并非 A 而是 B、不在 A 而在 B、不在 A 而是 B、不在于 A 而在于 B、不是 A，是 B、与其说 A 不如说 B、A 而非 B、而不是 B）。要否定就直接给否定判断，要立论就直接给肯定命题；引述他人原文或标准条文时加引号并标明来源 | 先否后立把两个判断压进一句，常用对比掩盖论证不足 |

### C3　明确不算要求的（避免把偏好当规范）

字号、行距、页边距、页数、是否用三线表、标题层级用"1"还是"一、"、参考文献条数、图表数量——除任务方另有规定外，均属排版偏好，不得作为"不符合要求"判罚；只能作为建议提出。
